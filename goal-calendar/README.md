# Goal Calendar

Минималистичная версия календаря целей.

## Что исправлено в v1.0.2

- Возвращена более минималистичная тёмная тема.
- Выровнена кнопка `+`.
- Убраны лишние визуальные перекосы и пёстрые градиенты.
- Блок `Заметка дня` поставлен под календарь и выровнен по его ширине.
- Сохранились модальное окно добавления цели и адаптивная мобильная версия.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
