# Goal Calendar

Версия 1.1.1

## Что изменено
- Добавлен общий контейнер ширины `max-w-[720px]` для мобильной версии.
- Карточки прогресса, календарь, цели и заметка теперь выровнены по одной ширине.
- Тема сделана темнее.
- Шрифты сделаны менее жирными: большая часть `font-black` заменена на `font-semibold` / `font-medium`.
- Убраны яркие фиолетово-синие акценты, интерфейс стал спокойнее и темнее.

## Запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```
