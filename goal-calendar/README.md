# Goal Calendar

Черно-серая версия с уменьшенным интерфейсом.

## Что изменено в v1.0.4

- Сохранён понравившийся круглый плюсик.
- Тема переведена в чёрно-серую гамму без лишних оттенков.
- Интерфейс сделан чуть компактнее.
- Шрифт настроен более аккуратно и современно.
- Блок `Новая цель` убран из основной страницы.
- Блок `Ближайшие цели` оставлен.
- Добавление новой цели работает через кнопку `+` и модальное окно.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm install
npm run build
```
