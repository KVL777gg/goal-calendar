# Goal Calendar

Версия 1.0.7

## Что изменено
- В широком виде кнопка `+` вынесена к правому краю.
- Тема переделана в стиле Apple: мягкий тёмный фон, стеклянные карточки, аккуратные границы, SF-подобный шрифт.
- Количественные цели вводятся вручную.
- Сохранены календарь, список целей, ближайшие цели и заметка дня.

## Запуск
```bash
npm install
npm run dev
```

## Сборка
```bash
npm run build
```
