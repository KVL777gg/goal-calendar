# Goal Calendar

Версия в теме как на референсе.

## Что изменено в v1.0.3

- Возвращена тема, похожая на референс из скрина.
- Цифры в календаре сделаны как на фото: крупные, белые, на тёмных карточках.
- Серия теперь показывается с огоньком.
- Блок `Заметка дня` возвращён в самый низ правой колонки.
- Сохранены форма новой цели и блок `Ближайшие цели`.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
