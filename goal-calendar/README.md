# Goal Calendar

Версия 1.0.6

## Что изменено

- Убрано `г.` из верхней даты.
- Тема обновлена на графитовую: тёплый чёрный, графитовые карточки и светлые акценты.
- В количественных целях прогресс теперь вводится вручную.
- Кнопка `+` сохранена.
- Сохранены блоки календаря, ближайших целей и заметки дня.

## Запуск

```bash
npm install
npm run dev
```

## Сборка
