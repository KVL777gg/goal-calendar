# Goal Calendar

Версия 1.1.0

## Что изменено
- Плюсик в мобильной версии теперь находится в одной строке с датой, как и в широкой версии.
- Убрана отдельная мобильная строка для кнопки добавления.
- Сохранена одинаковая ширина карточек на телефоне.
- Сохранён тёмный Apple-подобный стиль.
