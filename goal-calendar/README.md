# Goal Calendar

Мобильный календарь целей на React + Vite + Tailwind.

## Исправления v1.0.1

- Исправлен обрезанный календарь на телефоне.
- Кнопка `+` теперь открывает форму как модальное окно.
- Нижние нерабочие вкладки убраны.
- Добавлена защита от горизонтального скролла.
- Улучшены размеры карточек календаря для iPhone/Safari.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
